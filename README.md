# HBC — каталог бизнесов и специалистов Хайфы (рабочее название)

Русскоязычный каталог бизнесов и специалистов Хайфы. Один сайт на Next.js работает и как обычный сайт,
и как Telegram Mini App (бот `@haifabcbot`).

- **Тестовый адрес:** https://haifa-catalog.vercel.app
- **Техническое задание (источник истины):** https://claude.ai/artifact/FRC2GByay4wHeq3jcMyfbV
- **Для новой сессии Claude:** начните с [`CLAUDE.md`](CLAUDE.md) — там статус, доступы, решения и следующие шаги.

## Стек

Next.js 16 + TypeScript + Tailwind CSS 4 на Vercel · Supabase (Postgres, Auth, Storage) · Cloudflare (Turnstile) · карта MapLibre + OpenFreeMap ·
Google Cloud (вход через Google, Places API для отзывов) · Telegram Bot API.

## Структура

```
src/app/                 страницы (App Router): главная, [section], [section]/[slug], поиск, вход, профиль, кабинет, админка
src/app/k/[code]/        короткая ссылка карточки для QR-кода (301 на адрес карточки)
src/app/kabinet/         кабинет владельца: карточки, редактор (kartochka/[id]), новая карточка, заявки, отзывы, статистика
src/app/admin/           админка: вкладки (очередь, правки без проверки, карточки, пользователи, справочники, импорт, журнал),
                         proverka/[id] — «было — стало», kartochka/[id] — управление карточкой
src/app/actions/         серверные действия: public (отзыв, жалоба, заявка, права), cabinet, admin, import
src/app/api/auth/        вход через Telegram (Mini App и виджет), привязка аккаунтов, выход
src/app/auth/callback/   возврат после входа через Google
src/components/          интерфейс: шапка, карточки, вход, Telegram-мост
src/components/listing/  карточка: listing-view.tsx (все блоки), blocks/ (видео, слайдер «до и после», фото крупно, запись к мастеру), share-panel.tsx
src/lib/blocks/          типы блоков (types.ts), устаревшее (expire.ts), модерация (moderation.ts), проверка данных (sanitize.ts)
src/lib/editor/          схемы полей редактора для каждого блока
src/components/editor/   редактор карточки, поля, загрузка и сжатие фото
src/lib/server/          сессия и права, капча и ограничение частоты, правка карточек
src/lib/                 Supabase-клиенты, вход, проверка подписи Telegram, данные и поиск, SEO-разметка, форматирование
src/i18n/ru.ts           все тексты интерфейса (готово к добавлению иврита, английского, арабского)
supabase/migrations/     схема базы, правила доступа (RLS), справочники
scripts/supabase-stub.py подмена Supabase для проверочной сборки без интернета (с примерными карточками из миграции)
public/demo/             файлы примерных карточек (PDF-меню)
public/import-shablon.csv шаблон таблицы для импорта карточек
```

## Локальный запуск

1. `npm install`
2. Скопировать `.env.example` в `.env.local` и вписать секреты (файл не попадает в репозиторий).
3. `npm run dev` → http://localhost:3000

Проверки перед отправкой: `npx next typegen && npx tsc --noEmit && npx eslint src && npm run build`.
